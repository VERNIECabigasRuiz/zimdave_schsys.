# Grades Entry and Principal Lock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Subject teachers enter one period grade (60–100) per learner for their Grades 1–10 loads; the principal locks a grading period for the whole school and can unlock one class or the whole period; advisers, principal and admin see grades read-only.

**Architecture:** New namespace `App\Grading`. Storage: `Grade` (enrollment × subject × period), `GradeLock` (school × period), `GradeUnlock` (section × subject × period). `GradeRules` answers "what is this class's status" and "which learners are on this sheet"; `GradeRecorder` does every write under a Symfony lock; `GradeVoter` gates EDIT / VIEW / VIEW_SECTION / LOCK. Screens mirror SF8's pattern (teacher controller + school controller sharing templates).

**Tech Stack:** Symfony 8.1, PHP 8.4, Doctrine ORM + migrations, Twig, Symfony Form + Validator, symfony/lock, PHPUnit (KernelTestCase / WebTestCase).

**Spec:** `docs/superpowers/specs/2026-10-30-grades-design.md`

## Global Constraints

- Branch `feature/grades` (off `feature/sf8`). Schema only via `php bin/console make:migration` + `doctrine:migrations:migrate` (dev and `--env=test`). Never `schema:update`.
- PHPUnit only through the scratchpad runner `pu.ps1` (PowerShell `Start-Process`; Avast suspends piped php.exe), always with a path argument. The full suite takes ~7 minutes.
- Tests build services with `new`, use `SchoolFixturesTrait` and `ClockSensitiveTrait::mockTime`. Fixture school year 2025-06-01 .. 2026-04-30 (`schoolYear(2025, current: true)`); default mocked now 2025-08-22 10:00. Fixture school years need their grading periods (use the existing `rebuildGradingPeriods()`).
- "Today" is `SchoolClock::now()`.
- Gradable: section in the current school year, grade level `GradeLevel::Grade1`..`Grade10` (values 1–10), subject without components.
- Grade values: whole numbers 60–100. Blank = not graded; clearing a grade deletes its row.
- Parent subject grade = `(int) round(average of component grades)` (PHP round, half up), only when every component has a grade; never stored.
- Status enum `ClassGradeStatus`: `Open = 'open'`, `Closed = 'closed'`, `Locked = 'locked'`, `Unlocked = 'unlocked'`; labels "Open", "Closed", "Locked", "Unlocked for corrections".
- Exact messages (verbatim): "Enter a grade from 60 to 100." · "{Term 1} is locked by the principal." · "{Term 1} isn't open for grading." · "{Term 1} hasn't been opened for grading yet." · "{Term 1} is already locked." · "{Term 1} is not locked." · "This class is already unlocked." · "This class is not unlocked." · "The class list changed while you were editing. Check the rows and save again." · flash "Saved {Term 1} grades for {n} learners." (`{Term 1}` = `GradingPeriod::getLabel()`).
- Rows: males first, then females, by name (`EnrollmentRepository::findClassList` order).
- Every POST with fields is a Symfony Form; bare POST buttons use `#[IsCsrfTokenValid]` as SF2/SF8 do.
- Never stage `assets/controllers.json` or `config/reference.php`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. The admin closes the period while a class is unlocked (stays editable) or while it is open and unlocked-free (becomes Closed); the principal locks a period the admin already closed (allowed when the school has grades in it). (Tests in Task 2 and Task 3.)
2. The principal locks the period while a teacher has the sheet open — the teacher's POST is refused with "Term 1 is locked by the principal." and nothing is saved. (Test in Task 5.)
3. A load reassigned to another teacher mid-term — the old teacher loses access (403), existing grades stay. (Test in Task 4.)
4. MAPEH average: one component missing → blank; .5 rounds up (84.5 → 85). (Test in Task 2.)
5. A learner dropped or transferred out — listed read-only with status, existing grade kept, a posted value for them ignored. (Tests in Tasks 2–3.)
