# Staff IDs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Teachers and principals print their own Big (100 × 138 mm) or Small (CR80, front + back) DepEd ID as a PDF, signed by the principal or the SDS from an admin Divisions list.

**Architecture:** A `Division` entity (admin CRUD) matched to schools by their existing region + division pair; an ID signature upload on `School`; `StaffIdDetails` (emergency contact, GSIS No.) per user; a `StaffIdCardBuilder` that turns a person into a readonly `StaffIdCard`; a `StaffIdPdf` rendering Twig to dompdf; a `MyIdController` page for the signed-in person.

**Tech Stack:** Symfony 8.1, Doctrine ORM + migrations, Twig, dompdf, GD, PHPUnit (WebTestCase / KernelTestCase).

**Spec:** `docs/superpowers/specs/2026-11-02-staff-ids-design.md`

## Global Constraints

- Each person prints only their own ID; no route prints another person's ID.
- My ID exists only for a user assigned to a school this S.Y. (`SchoolAssignmentRepository::findForUser`) as teacher or principal; otherwise the menu item is hidden and every My ID route is 403.
- Without a photo or a service record Present row (`ServiceRecordEntryRepository::findCurrent`) the PDF buttons are disabled and the PDF routes redirect to My ID with flash `error` "Add your photo and a current (Present) service record row before printing your ID."
- Every other missing value prints as an empty line, never a placeholder like `<Position>`.
- SDS position default: `Schools Division Superintendent`. Principal position fallback: `School Principal`.
- File names: `ID (Big) - DELA CRUZ, JUAN.pdf` / `ID (Small) - DELA CRUZ, JUAN.pdf`, ASCII fallback via `u()->ascii()` as in `ServiceRecordPdf::asciiFilename`.
- Paper: Big on long bond `[0, 0, 612, 936]`; Small on letter `[0, 0, 612, 792]`. Cards at actual size (mm in CSS).
- Images go to dompdf as data URIs (no remote loading); photos as JPEG, signatures/logos as PNG (reuse the `webpDataUri` approach from `IdCardBuilder`).
- Tests: `php bin/phpunit`; never two phpunit runs at once. Add `StaffIdDetails` and `Division` to `SchoolFixturesTrait::clearSchoolData` (before `User`/`School`).

## Review Focus

- A teacher at a school with no principal this S.Y. (Individual plan): head prints blank, no error.
- A principal whose school's region+division has no Divisions entry, or an entry with no signature: blank SDS lines, no error.
- Names with Ñ and an extension (e.g. `PEÑA JR.`): PDF downloads; card shows `JUAN A. PEÑA JR.`.
- A person without a PDS: name falls back to the account's full name; numbers print blank.
- Editing a Division to a region+name pair already on the list: form error, not a 500.
