# Class Sections Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Sections per school and S.Y. with an optional adviser; principal/admin manage them; Individual-plan teachers create their own; teachers see their advisory.

**Spec:** `docs/superpowers/specs/2026-10-16-sections-design.md`

## Global Constraints

- No git; TDD; one phpunit process at a time; migration via make:migration (dev + test).
- Writes go through `SectionManager`, which refuses when `PlanLimits::blockedReason()` is not null.
- Adviser must be a current-S.Y. teacher of the same school; one advisory per teacher per S.Y.
- Shared page pattern = `SchoolTeacherController` (voter `SchoolVoter::MANAGE`, layout by role).

## Review Focus

1. A principal can't pick another school's teacher as adviser by tampering with the adviser id — Task 2 test.
2. Bring back never copies advisers and skips existing names — Task 3 test.
3. An expired-plan school can view sections but every write is refused — Task 3 test.
4. A Basic-plan teacher can't reach `/teacher/section`; an Individual-plan teacher can't create a second section — Task 4 test.
5. Deleting a teacher's account/assignment leaves their old section with no adviser rather than an error — Task 1 (onDelete SET NULL) test.
