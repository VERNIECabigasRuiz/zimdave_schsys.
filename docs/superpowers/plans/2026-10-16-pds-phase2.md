# PDS Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** My Profile tabs for PDS sections III–VIII (rows added/removed per section) and those rows printed in the PDS PDF with C5–C11 continuation pages.

**Architecture:** Five row entities owned by `PersonalDataSheet` (+ three JSON string lists for item 31–33); one generic controller helper + one generic card template drive five of the six tabs; `PdsPdfRenderer` gains per-section row slicing and continuation pages.

**Tech Stack:** Symfony 8.1, Doctrine ORM 3.7 + migrations, Form CollectionType, Stimulus `collection` controller (exists), Dompdf.

**Spec:** `docs/superpowers/specs/2026-10-16-pds-phase2-design.md`

## Global Constraints

- No git: no commit steps; each task ends with its tests green, the plan ends with the full suite.
- Schema changes via `make:migration` + `doctrine:migrations:migrate` (dev and `--env=test`).
- All list rows' constraints carry `groups: ['Default', PersonalDataSheet::LISTS]`; every list form sets `validation_groups => [PersonalDataSheet::LISTS]` so section I never blocks a list save.
- Order rules (spec): education by level then yearFrom; eligibility by user order; work: present first then dateFrom desc; training: dateFrom desc; voluntary: dateFrom desc, undated last. One implementation (`PersonalDataSheet::sortedX()`), used both to renumber `position` on save and by the PDF.
- Collection caps: lists `Count(max: 100)`, children `Count(max: 30)`.
- Form rows (PDF): education 5 (one per level), eligibility 7, work 24, training 17, voluntary 9, other info 7.
- Datalist suggestions exactly as listed in the spec.

## Review Focus

1. Editing a work row from "present" to an end date re-sorts it on the next save (not stuck on top) — test in Task 3.
2. A list save while section I is empty still succeeds — test in Task 2 (one section) and covered generically.
3. Deleting every row of a section leaves it valid and prints N/A in the PDF's first row — tests in Tasks 2 and 6.
4. Two education rows at the same level: first prints on page 1, second on C8 — test in Task 6.
5. Every main grid full still yields exactly 4 main pages — test in Task 6.
